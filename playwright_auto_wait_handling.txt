Regex or regular expression is a pattern language that programmer define to bind, search or extract data within the sequence 

some metacharacters group:

"."  match any characters

"^" begin of the sequence 

"$" end of the sequence

"[]" match a character in list within opening square bracket and close square bracket

example :[abc] match a or b or c example

"[^]" negative character class this mean match the character no include character set in []

example Regex.Replaces(input, "[^A-Za-z]","") delete or replace all characters not letter by ""

"()" Group: gather many characters become a group, apply repeat (+,*,{}) in group, create Capturing Group ->use again \1,\2 ,create OR complicated group(abc|def)

"|" OR example: cat|dog ->match "cat" or "dog", (yes|no) match "yes" or no

"\"escape (change the meaning of the character), Escape have two functions: 

change specials character to normal character(\. match the real dot, \* match sign *, \+ match sign +, \| match sign |)

change normal character to specials character(\d digit(0-9), \w word char(A-Z, a-z, 0-9,_), \s whitespace, \b word boundary,\t tab, \n newline,\r carriage return)

Character Classes [] define a set characters, any one of which can occur in an input string for a match to succeed :

\d digit ->123...,

\w letter+ number+ ->word_word1

\s whitespace ->  space, tab

\D not digit 

\W Not word 

\S Not whitespace

Quantifiers : Quantifiers specify how many instances of a character, group, or character classes must be present in the input for a match

to be found

* matches zero or more times

+ matches one or more times 

? matches zero or one times

{n} matches exactly n times

{n, } matches at least n times

{n, m} matches from n to m times 

Anchors  specify a position in the string where a match must occur

^ beginning the string

$ end of  the string

\b word boundary example : /bcar/b car is Toyota oto ->match car , ccccar -> not match

\B not word boundary

Groups 

() sign help split regex to the subexpression and capture match string part.

Match a subexpression that's repeated in the input string

apply repeat across the entire character cluster

use group in Replace to reuse value 

take value of each group to match. Groups in C#

capturing vs Non-capturing group

Capturing group(...) store match result, have index: Group[1], Group[2],....

Non-Capturing group(?:...) match but not store
