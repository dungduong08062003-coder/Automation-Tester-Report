WebElement Command

WebElement biểu diễn cái htmlElement, Element là cái thành phần mình thấy trong website ví dụ nút đăng nhập giỏ hàng hay cái sản phẩm, là những cái mà user thấy tương tác hoặc trình duyệt dùng để hiện thị nội dung

Clear(); làm rỗng hay xóa tất cả dữ liệu trong ô input hay TextArea mà ta chỉ định

Click():Mô phỏng hành động nhấn chuột trái vào các Element

Displayed():kiểm tra xem thuộc tính có hiện thị không trả về true/false nếu element hiển thị thì sẽ trả về True, còn nếu bị ẩn dấu là false, còn nếu là không có sẽ throw 1 cái ngoại lệ NoSuchElement

Enabled().kiểm tra xem element có tương tác được không, trả về true hoặc false

Selected() dùng khi ta tương tác với Checkboxes, Select Option, Radio Button True nếu đã được chọn còn false nếu chưa

Submit() hành động nhấn chuột trái khi dùng trong form

Text() trả về nội dung UI hiện thị

TagName() ví dụ <h1>hhh</h1> Trả về là h1

FindElement And FindElements Commands 

FindElement dùng khi có muốn tương tác với 1 Element hoặc Element đầu tiên(nếu không có sẽ Throws ra 1 cái NoSuchElementException)

FindElements dùng khi muốn xử lý nhiều hoặc muốn kiểm tra số lượng duyệt danh sách (không có sẽ trả 1 danh sách rỗng)


các cách tìm Element ưu tiên theo thứ tự

1 By.Id là id duy nhất trong DOM truy cập nhanh nhất ít bị thay đổi
2 By.Name Thường dùng trong Form, ổn định có thể trùng nhưng ít hơn class
3 By.CssSelector linh hoạt (ví dụ kết hợp nhiều điều kiện input[type=’Password’].form-control)
4 By.Xpath mạnh nhất nhưng duyệt cây DOM, dễ gãy khi UI đổi layout, chậm
5 By.ClassName nhiều element dùng chung 1 class hay bị đổi tên class, 
6 By.LinkText/PartialLinkText dùng khi muốn lấy link từ element mà dev gắn link vào nó
