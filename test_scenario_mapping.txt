Dependency Injection 

RestSharp provide the package RestSharp.Extensions.DependencyInjection to integrate with Microsoft Dependency Injection.

It supports the use of IHttpClientFactory to properly manage the lifecycle of HttpMessageHandle instances:

This avoids socket exhaustion when RestClient is registered as a transient dependency.

It also handles DNS rotation when the endpoint changes its IP address, avoiding the issue of "freeze" DNS that can occur when using a long-lived singleton HttpClient.

Best practice:

Register RestClient as a transient service  and rely on IHttpClientFactory to manage the HttpMessageHandle lifecycle

DI helps control headers per client, apply policies  per named client, and avoid the caching pitfalls of the simple client factory. 

Reusing HttpClient

Method 1: Pass an HttpClient or HttpMessageHander directly to the constructor

example: 

var httpClient = new HttpClient();

// can be set BaseAddress if need:

//httpClient.BaseAddress = new Uri("https://api.example.com");

var client = new RestClient(httpClient);

 Important note: when providing tour own HttpClient or HttpMessageHandler, not all RestClientOptions will be applied. Only a limited set of options will still work: HttpClient

BaseAddress is used to set the base address of the HttpClient instance if it has not already been set.

MaxTimeout is used to cancel the request via a CancellationTokenSource when the timeout is exceeded.

UserAgent will be added to the RestClient.DefaultParameters list as a HTTP header. This will be added to each request made by the RestClient, and the HttpClient instance will not be modified. This allows HttpClient instance to be reused in scenarios where different User-Agent headers are required.

Expect100Continue: Control behavior Expect: 100-continue

Blazor WebAssembly support 

In Blazor WebAssembly, many RestClient's constructors cannot be used  due to platform limitations.

Only Constructors that accept an HttpClient or httpMessageHandler should be used.

 

example 

class Post
{
    public int UserId { get; set; }
    public int id { get; set; }
    public string title { get; set; }
    public string body { get; set; }

 

}
internal class program
{
    
    static async Task Main(string[] args)
    {
        RestClient client = new RestClient("https://Api.example.com");
        //GET
        RestRequest GetRequest = new RestRequest("/posts/1", Method.Get);

 

        var post = await client.GetAsync<Post>(GetRequest);
        Console.WriteLine(post.title);
        Console.WriteLine(post.body);

 

        //POST
        RestRequest PostRequest = new RestRequest("/posts", Method.Post);
        PostRequest.AddJsonBody(new
        {
            title = "hellp restsharp",
            body = "this is test Post",
            userId = 1
        });
        var response = await client.PostAsync(PostRequest);
        Console.WriteLine(response.StatusCode);
        Console.WriteLine(response. Content);
    }
}

 

Preparing requests

Create a request

var request = new RestRequest(resource) // resource is the sub-path of the client base path

The default request type is GET and you can override it by setting the Method property. You can also set the method using the constructor overload:

var request = new RestRequest(resource, Method.Post);

 

Request header are key-value pairs that are attached to an HTTP request to provide metadata to the server.

Example of common headers:

Authrization

X-API-Key

Accept

User-Agent

The header is not in the body, not in the URL.

AddHeader(string name, string value);

AddHeader<T>(string name, T value);//value will converted to string

AddOrUpdateHeader(string name, string value)// replaces the header if it already exists

 

Meaning of each one 

AddHeader(string, string)

request.AddHeader("X-Key","abc123");

add a new header

no duplicate string

 

AddHeader<T>(string,T)

request.AddHeader("X-Retry-Count", 3);

Value will be converted to string

Convenient when transmitting number, enum 

 AddOrUpdateHeader

request.AddOrUpdateHeader("Authorization", "Bearer token");

 if the header exists -> replace
