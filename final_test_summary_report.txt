Authentication tokens give permission to access an API (like a key) , while usage tokens (such as in AI API) represent how much you pay for using service(like money)

Synchronous(sync): A synchronous API call blocks execution until the server returns a response. You wait until the API finishes and return a response.

Asynchronous(async) : An asynchronous API call returns immediately and processes the request in the background, delivering the results later . You don't wait. The API works in the background and response later

Deserialize:  Convert received data(usually JSON) into the object that your program can use 

Serialize: Convert an object into a format(usually JSON) that can be sent or stored 

RestSharp is a wrapper around HttpClient that allows you to do the following:

Add default parameters of any kind (not just headers) to the client, once

Add parameters of any kind to each request (query, URL segment, form, attachment, serialized body, header) in a straightforward way

Serialize the payload to JSON or XML if necessary

Set the correct content headers (content type, disposition, length, etc.)

Handle the remote endpoint response

Deserialize the response from JSON or XML if necessary

API client the best way to call an external HTTP API is create  a typed client, which encapsulates RestSharp call and don't expose the RestClient instance in public.

External HTTP API is an API that hosted outside your system and accessed over  HTTP/HTTPS

example : Payment APIs(Paypal), Map API(google maps), Authentication APIs(OAuth providers), AI API (chatgpt OpenAI), Social API(facebook, X)
