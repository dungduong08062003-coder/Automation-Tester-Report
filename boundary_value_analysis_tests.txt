Browser Factory and WebDriver Factory:

A Factory Pattern is used to encapsulate the complexity of creating an object.

Two important idea behind Factory pattern :

hide the logic initializing logic in side factory.

refer to the object using a common interface instead of the concrete class 

steps:

1.We store browser value in the JSON file like appsetting.json  ("Environment:"{"Browser":"Edge",.....})

2. we create TestConfig class read value from the JSON file and exposes them as properties

3. Create a DriverFatory class that read the browser value from TestConfig and use its code some cases create IWebDriver when we use the browser application when automation testing like the case use Edge or Chrome  its in createDriver Method 

4.In TestBase class when method setup we will call createDriver Method to create Browser
